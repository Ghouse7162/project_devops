
# QuickCart Support Portal

A simple customer support website built with HTML and CSS.

## Features
- Order tracking support
- Missing item support
- Returns and refunds information
- Responsive support cards

## Technologies
- HTML
- CSS
- Git and GitHub

## Local Setup
1. Clone or download this repository.
2. Open `index.html` in a web browser.

## Planned Cloud Deployment
- AWS EC2 for web hosting
- Linux server administration
- Network and security configuration
- Monitoring and troubleshooting
